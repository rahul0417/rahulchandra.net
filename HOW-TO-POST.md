# How to add a post

Easiest: ask Claude "post this to my site" and paste your notes.

Doing it yourself:
1. Add a file to `_posts/` named `YYYY-MM-DD-short-title.md` (e.g. `2026-11-20-chatgpt-cold-emails.md`).
2. Start it with:

   ---
   title: Your title
   topic: AI tests        (or Sales, Marketing, Product, Customers, Notes)
   summary: One sentence shown on the home page.
   ---

3. Write the post below in plain text (Markdown).
4. Commit and push. The site updates in about a minute.

Images go in `assets/` and are added with `![description](/assets/image-name.png)`.
